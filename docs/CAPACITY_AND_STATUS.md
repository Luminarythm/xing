# 容量控制与运行状态

仅使用本地合成数据，不接真实站点或平台；当前schema v7（站点持久分页序号）。

## 容量契约

启动 `python -m geo` 前可配置以下环境变量。直接构建Service时可传入Limits对象，默认值相同。

| 环境变量 | 默认值 | 含义 |
| --- | --- | --- |
| GEO_MAX_QUERY_EVENTS | 10000 | 报告/CSV匹配事件数；保留删除选择的事件+任务+复核记录总数；内部完整审计读取条数 |
| GEO_MAX_QUERY_BYTES | 16777216 | 一次事件/复核读取的UTF-8 payload字节上限；保留选择标识字节与计划大小上限 |
| GEO_MAX_RESPONSE_BYTES | 16777216 | GET JSON或CSV编码后字节上限；保留计划也在写入或删除前预检此预算 |

条数必须为正整数，字节配置至少1024；配置错误阻止启动。上限是单次请求/读取预算，**不是整个进程内存上限**；事件、复核投影、序列化仍会占用额外内存，多并发请求仍会叠加。提高限制需要本地容量评估。

报告和CSV先在数据库中应用站点、时间、kind、平台、入口、模型和source筛选，再逐条读取，在JSON解析前检查payload字节与条数。超限返回 `422 {"code":"capacity_exceeded","error":"..."}`，不返回部分统计或半份CSV。GET响应在发出成功响应头前完成容量检查。写操作响应不套用GET输出预算，避免写入成功后因响应预算向调用方错误宣称操作失败。

事件分页保持默认100/最多500条，与报告条数上限独立；单页仍受读取字节与响应预算限制，读取预算保守包含用于判断下一页的额外一条。收到422时缩小时间窗、增加筛选或减小分页limit。单条证据本身超限时需调整容量配置。这里没有异步导出任务，也不保证全库查询的固定响应时间。

品牌投影在数据库中选择本次回答、指定配置、复核序号上限内每个品牌的最后一次判断，不再把全部审计历史加载进内存。站点与复核历史HTTP接口均为分页对象，默认100/最多500，单页受字节预算限制；内部Brands.reviews完整读取方法仍受条数限制。保留预览与执行已加入组合选择预算及计划预检，见 AUDIT_AND_RETENTION.md。清单在读取正文前检查数据库存储字节，导入前检查存储和响应预算。内部Service.sites完整列表仍供本地调用，不是HTTP分页入口。GET输出上限不等同于所有内部读取上限。状态聚合保留单独的两秒查询预算。

## 报告范围

所有筛选先去除首尾空格，再用于SQL、报告范围和游标绑定。`kind=answers` 和 `kind=%20answers%20` 结果相同。只查询日志时 `answer_scope=excluded_by_log_filter`，回答数、提及数、引用数及分组均为null；只查询回答或使用回答专属筛选时，爬虫指标继续为null。**null表示指标不在此次查询范围或比例未知，0表示在查询范围内实际计数为零。**

报告与CSV属于即时查询，品牌配置可固定，但多次HTTP请求之间没有共同数据库快照；并发写入可能使分别请求的结果不同。事件游标仍使用已有的事件/品牌/复核上限。本轮数量一致性验收在无并发写入的合成数据库执行。

## 管理员状态接口

`GET /api/v1/status` 需要实例管理员凭证，不接受查询参数；站点采集密钥不可访问。返回schema版本、站点/事件/清单/品牌配置/复核数量、任务状态计数、到期queued数、租约过期running数、生效容量配置和 `providers=["mock"]`。不返回提示词、回答、密钥、任务request_key或数据库路径。

状态查询使用只读连接与一致读取事务，检查v7及必需表；数据库缺失、打不开、结构不完整或查询超时返回503与通用错误。返回database_timeouts_ms显示普通连接的忙锁/查询时限。不会重建缺失文件，也不会领取任务、更改租约或执行修复。这里仅检验可读性和必要结构，不能替代备份完整性/恢复演练或实际写入检查。

公开 `/health` 仍只表示HTTP进程存活；数据库异常时它可以返回200。需要判断数据服务状态时使用有凭证的 `/api/v1/status`。未安装后台巡检或通知任务。

## 本地验收

`python -m unittest discover -s tests -v` 包含条数精确边界、UTF-8字节边界、CSV公式转义后容量、HTTP无部分输出、状态鉴权/敏感内容排除/缺库不重建、复核最新记录，以及1,200条合成回答跨多页核对：筛选600条，报告/CSV/分页事件集合一致，限制降为599时拒绝。

服务层固定规模基线见 AUDIT_AND_RETENTION.md；HTTP多连接与进程驻留内存峰值基线见 SITES_AND_DATABASE.md。仍待更大数据量与生产条件验收；真实provider仍待明确授权与样本准备。

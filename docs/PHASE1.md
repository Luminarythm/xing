## 立即可执行的本地验收

1. 按 README 启动服务，执行 `python scripts/demo.py` 两次，核对报告没有增长。
2. 运行 `python -m unittest discover -s tests -v`，覆盖鉴权、隔离、时间边界、适配器、原子性、重试、持久化及统计。
3. 用独立测试库导入授权脱敏 JSON 日志，确保 source/event_id 稳定；记录成功/拒绝数量。此步骤需运营者提供真实日志，当前未宣称完成。
4. 录入回答时标明平台、模型、入口、地区/语言、采样时间、prompt、原文和引用。先核对证据，再解释报告。

第一阶段退出条件：P01–P07 与必要数据治理完成，连续7天采集无未解释缺口；至少20条跨两平台真实可复核样本；周报能逐项回溯事实。若无法取得平台接口，保留人工适配路线，不将“接口已预留”表述为“平台已接入”。

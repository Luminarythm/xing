# 固定时间窗本地报告包

`python -m geo.bundle` 从已有 schema v8 数据库导出 ZIP，不联网、不迁移数据库、不调用平台。需要本机数据库读取权限及输出目录写入权限；不经过 HTTP，也不使用 API token。只使用合成数据进行验收。

```powershell
python -m geo.bundle --db data/geo.sqlite3 --site <site-id> --start 2026-10-30T00:00:00Z --end 2026-10-31T00:00:00Z --output data/report-20261030.zip
```

先用现有流程创建站点并导入示例数据，替换实际数据库路径和站点 ID。输出父目录必须已存在。起止时间必须明确带时区，统一为 UTC，包含 start、不包含 end；不提供隐式“最近七天”。可选 `--platform`、`--surface`、`--model`、`--source`、`--kind answers`、`--brand-config-id`、`--inventory-id`。参数的空格处理、精确大小写筛选与现有报告一致。包中质量报告固定为回答范围、dataset=all；若仅需示例数据可加 `--platform synthetic`。它是精确平台筛选，与质量接口忽略大小写识别 synthetic 标签的 dataset 选项不同。`--kind logs` 被拒绝；日志专属报告仍用原有接口。

ZIP 只包含以下四个文件：

| 文件 | 内容 |
| --- | --- |
| report.json | 基础计数、品牌定义、品牌提及及页面覆盖 |
| quality.json | 当前保留且去重后的回答质量、各指标分母与未知值 |
| manifest.json | 格式版本 1、schema、站点、生成时间、UTC 时间窗、两份报告的实际筛选、配置/清单 ID、预算，以及其余三个文件的字节数和 SHA-256 |
| README.txt | 英文可移植的范围和指标说明 |

不导出原始 prompt、回答正文、事件 ID、证据链接、密钥或数据库路径。不代表自动脱敏：站点名称、域名、品牌别名、页面 URL、来源等筛选值仍可能敏感，分享前检查。建议放在已被 Git 忽略的 data/ 下。摘要用于发现文件意外变化，不提供签名或真实性背书；manifest 不包含自己的摘要。

基础报告和质量报告使用同一只读主库连接、同一 SQLite 读事务；品牌复核需要的临时表只写连接私有临时库。配置与清单默认选择该快照中的最新版本，也可指定历史 ID。清单读取复用已有事务，不再次 BEGIN。导出中途其他连接提交样本、配置或复核，不改变包内快照；非 WAL 模式下读事务可能暂时阻塞写入者。这里不自动修改数据库日志模式。

generated_at 是快照建立附近的 UTC 时间，不是可用于回放的数据库版本号。导出后文件内容固定；再次导出同一时间窗，仍可能因补录、复核或保留删除产生不同结果。没有导出原始事实，不能仅凭包重算所有指标。分别请求原有 HTTP 报告仍不共享快照。合成数据不证明真实曝光，抓取、引用和提及继续使用各自定义，空分母为 null。

查询复用 `GEO_MAX_QUERY_EVENTS` / `GEO_MAX_QUERY_BYTES`，`GEO_MAX_RESPONSE_BYTES` 额外限制四个成员的未压缩 UTF-8 总字节数（默认 16 MiB，不含 ZIP 容器开销）。超限拒绝，绝不截断。该预算不是进程总内存上限。锁等待默认 2 秒，数据库快照计算截止默认 5 秒，可通过既有 `GEO_DB_BUSY_TIMEOUT_MS` / `GEO_DB_QUERY_TIMEOUT_MS` 配置为 1–60000 毫秒。截止检查覆盖 SQLite 进度与报告计算完成处，不是 Python 计算或文件压缩的强制抢占超时。

先在目标同目录写临时文件并刷新，再用硬链接原子发布完整 ZIP；已有同名文件或竞争创建者均不覆盖。文件系统不支持硬链接时失败，不降级为覆盖式重命名。可捕获异常和 KeyboardInterrupt 会清理本次临时文件；强制杀进程/断电可能留下 `.xing-report-*.tmp`，不能承诺崩溃后的自动清理或目录持久性。无自动上传、定时导出或批量删除。

验收命令：`python -m unittest tests.test_bundle -v`。覆盖共享事务、WAL 并发变化、UTC 边界、固定配置/清单、空分母、清单摘要、源库未修改、正文排除、缺库/旧版本拒绝、容量、文件竞争、写入/发布/中断失败、锁等待/截止以及 CLI 实际执行。

## 离线校验与中文摘要（2026-11-01）

```powershell
python -m geo.bundle_check data/report.zip
python -m geo.bundle_check data/report.zip --summary
python scripts/bundle_load.py
```

校验器不连接数据库，不解压到磁盘，不显示包内README或未经检查的报告正文。成功输出JSON或中文纯文本；失败返回退出码1，不输出部分摘要。文本中的站点/筛选元数据采用ASCII JSON转义，中文名称会显示为Unicode转义，以阻断终端控制字符。Windows重定向需明确UTF-8时可使用 `python -X utf8`。

只接受格式v1、schema v8和四个固定成员，拒绝重复/额外成员、路径变体、符号链接、加密及非stored/deflate压缩。输入压缩文件最多为本地 `GEO_MAX_RESPONSE_BYTES` 加64KiB容器余量，解压总字节受同一本地预算限制；不会信任包内声明来提高限制。读取前检查声明大小，读取时再次限制实际字节。不采用固定压缩比限制，正常高重复数据也可通过。ZIP目录和JSON对象仍消耗额外内存，字节限制不是进程内存上限。

检查成员字节数/SHA-256，拒绝重复JSON键和NaN/Infinity。交叉检查站点、时间窗、筛选、品牌/清单ID、回答样本数、合成/未分类分组、质量指标分母和比例，以及引用率、提及计数范围、入口/平台计数总和。不是所有报告字段的完整schema验证，也不从原始事实重算页面覆盖或品牌命中；即使攻击者重新计算摘要，已实现的交叉约束仍会检查，但一致的伪造包无法据此辨真。

摘要明确当前保留样本、显式合成、未分类、字段未知和空分母，禁止将校验成功解释为真实性或综合GEO评分。本轮8项新增测试覆盖正常包、篡改后重算摘要、非法成员/JSON/压缩、容量、终端控制字符和CLI失败不输出部分摘要。

固定基线：Windows本地单次1,000条合成回答，回答正文每条50次重复短句；导出0.0806秒、校验0.0177秒、ZIP 2,585字节、未压缩4,317字节、Python tracemalloc峰值17,032,858字节。峰值覆盖导出和校验，不含建库/导入，也不包含SQLite等原生分配；读取有界文件时的缓冲预分配会影响峰值。包只保留汇总，不能把压缩比理解为原始样本压缩效果。该结果不是并发或生产性能保证，不足以证明大清单/长审计历史的性能。

## 分组约束与分块读取（2026-11-06）

校验增加品牌定义ID/名称唯一、品牌计数键一致、单品牌计数与总提及样本范围。一条回答可提及多个品牌，因此只检查最大单品牌数 ≤ 提及样本数 ≤ 品牌计数之和，不强求相加等于总数。人工复核后的多品牌计数仍可通过。

页面覆盖检查清单长度、页面URL唯一、逐页成功/失败/重定向数、观察布尔值、汇总页数和覆盖比例；清单外URL必须唯一且与清单不相交，并与观察页面数、声明AI请求数关联。1xx请求允许不属于成功/失败/重定向分类。日志被回答筛选排除时保持null；没有清单与空清单保留不同口径，空分母为null。主报告覆盖率必须与覆盖明细一致。仍不能仅凭包确认URL真实性、原始请求状态或品牌命中是否准确，也不是完整字段schema校验。

JSON浮点解析新增有限值检查，拒绝 `1e999` 等合法JSON语法但溢出为无穷的数值，包括未用于统计的字段。压缩输入和成员改为最多64KiB一块读取，累计大小仍按原预算拒绝；没有降低容量保护，也不做无限流读取。

运行 `python scripts/bundle_load.py --expanded` 增加5,000页清单与同一回答1,000次复核，保留1,000条合成回答。2026-11-06单次本地测量：
